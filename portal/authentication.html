Authentication and request signing

Every request is authenticated three ways: a client certificate, a certificate-bound access token and a signed request.

On this page
  • 1. Mutual TLS
  • 2. Token (client credentials, private_key_jwt)
  • 3. Signed requests

1. Mutual TLS#

Every connection must present a client certificate that is registered for your client. Connections without one are refused during the TLS handshake. Weak or non-AEAD cipher suites and TLS 1.1 and below are refused.

2. Token (client credentials, private_key_jwt)#

POST /oauth/token as application/x-www-form-urlencoded with grant_type=client_credentials, your client_id, client_assertion_type=urn:ietf:params:oauth:client-assertion-type:jwt-bearer and a client_assertion: a JWT signed with your registered private key (ES256 or PS256) with iss = sub = your client id, aud = the token endpoint, iat/exp at most 60 seconds apart, and a unique jti. Client secrets are not supported. The platform never holds your private key.

import { SignJWT } from "jose";
const assertion = await new SignJWT({})
  .setProtectedHeader({ alg: "ES256", kid: MY_KID })
  .setIssuer(CLIENT_ID).setSubject(CLIENT_ID).setAudience(TOKEN_ENDPOINT)
  .setIssuedAt().setExpirationTime("30s").setJti(crypto.randomUUID())
  .sign(MY_PRIVATE_KEY);

The access token lifetime is at most 5 minutes and it carries cnf.x5t#S256, the thumbprint of your certificate: it is rejected on any other connection.

3. Signed requests#

Every state-changing request and every signal request carries X-Request-Signature: a compact JWS (your registered key) over a JSON payload with htm (HTTP method), htu (path), dig (base64url SHA-256 of the exact body bytes), iat (within 60 seconds of the server clock) and jti (16 to 64 URL-safe characters, never reused).

import { CompactSign } from "jose";
import { createHash, randomBytes } from "node:crypto";
const payload = JSON.stringify({
  htm: "POST", htu: "/v1/signals/sim-swap/check",
  dig: createHash("sha256").update(body).digest("base64url"),
  iat: Math.floor(Date.now() / 1000), jti: randomBytes(18).toString("base64url"),
});
const jws = await new CompactSign(new TextEncoder().encode(payload))
  .setProtectedHeader({ alg: "ES256", kid: MY_KID }).sign(MY_PRIVATE_KEY);

An identical signed request cannot be replayed: the second use of a jti, or a timestamp outside the window, is rejected.
