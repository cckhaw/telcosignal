Has the SIM been swapped within maxAge hours?#

POST /v1/signals/sim-swap/check

Requires scope `sim-swap:check`. Answers are four-state: TRUE, FALSE, UNAVAILABLE, NOT_SUPPORTED. FALSE is returned only when the telco gave an explicit, valid negative; a timeout, error, invalid response or unsupported signal is never FALSE. Telco A speaks CAMARA SimSwap r4.3 `check`.

Is the device inside the circle?#

POST /v1/signals/device-location/check

Requires scope `device-location:check`. Answers are four-state: TRUE, FALSE, UNAVAILABLE, NOT_SUPPORTED. FALSE is returned only when the telco gave an explicit, valid negative; a timeout, error, invalid response or unsupported signal is never FALSE. SENSITIVE: needs explicit per-subject consent, a radius of at least 2000 m, and is limited to a few checks per subject per hour. The circle is processed in memory and never stored or logged. TRUE is inside, FALSE is outside; a partial overlap is UNAVAILABLE. Telco A speaks CAMARA LocationVerification r4.3 `verify`.
