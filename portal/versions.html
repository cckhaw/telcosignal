Versions and deprecation

The current API version is v1. Breaking changes are introduced as a new major version; a version is marked deprecated with a published sunset date before it is withdrawn. Version status is managed in the admin portal and shown in the dashboards.

CAMARA alignment

The telco-facing interfaces follow pinned CAMARA releases (SimSwap r4.3, DeviceSwap r4.3, CallForwardingSignal r4.3, KnowYourCustomer r2.2). The participant-facing API deliberately differs: four-state results, no 404 for unknown numbers, mandatory purpose and consent references, sender-constrained tokens.
