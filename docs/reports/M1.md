## Defects found by the tests and fixed (not suppressed)
1. Audit verifier ordered rows by the text alias (`ORDER BY seq` resolved to `seq::text`), so any chain longer than 9 rows would have been falsely reported as broken. Fixed (`ORDER BY audit_log.seq`).
2. Undici emitted an unhandled `AbortError` when the adapter abandoned a non-200 / oversized telco response: a crash vector against a hostile telco. Fixed with an error sink on the response body.
3. A replay-store outage during client authentication failed closed but reported 401; now 503 (no token issued either way).
4. Test harness: role passwords are cluster-wide; per-run derived passwords introduced.
